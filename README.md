# AstraInterject

Плагин открывает дополнительное окно прослушивания после каждого голосового ответа Astra. Пока окно активно, следующую фразу можно произнести без триггерного слова. После нового ответа цикл повторяется.

Окно открывается только после события `tts_completed` (Astra полностью договорила; `tts_started`/`tts_interrupted` отменяют его). Запись включается сразу на всё окно, голос пользователя отслеживается отдельным потоком реального микрофона (`getUserMedia`, эхо-подавление включено), а не событий визуализации. Отправляется только речь длиннее ~150 мс; тишина и щелчки отбрасываются через `discard`.

## Настройки

- «Продолжение диалога» включает и выключает функцию.
- «Окно прослушивания» задаёт, сколько секунд нужно начать говорить после ответа Astra (от 2 до 30, по умолчанию 8). После начала речи фраза дослушивается до конца и отправляется примерно через паузу окончания речи.
- «Одно продолжение за раз»: выключено — окно открывается после каждого ответа (цепочка); включено — одно окно после вызова по триггерному слову, дальше снова нужен триггер.
